## 見知らぬ世界。さて、どう生きる？
残業帰りか、通学の途中か。気がつくと、異世界の遺跡に倒れていた。  
「……また外れだ。勇者の器ではない」  
召喚した一団は、あなたを置いて去っていった。手元に残ったのは、背負っていた鞄ひとつだけ。

元の世界へ帰る門が開くのは、100日後。  
大陸では五つの国が争い、南では魔族の封印が破れつつある。  
帰り道を探すか、店を構えて根を下ろすか、騎士になるか、魔王を討つか、それとも魔王の側につくか。  
どう生きるかは、あなたが決めていい。

### 主な特徴
* **時間が流れる大陸マップ**：国々の軍勢や魔物も同じ時間の中で動く
* **鞄（バックパック）ビルド**：品物の置き場所を工夫し、隣り合わせの効果や合成で強化する
* **自動戦闘**：戦闘は自動で進行。勝てるかどうかは鞄の中身次第
* **マルチエンディング**：帰還・英雄・仕官・大陸統一など、たくさんの結末
* **キャラクリ（オリジナル職業）**：能力や特性を組み合わせてオリジナル職業を作成し、メタデータ付きPNGとして書き出し・共有可能
