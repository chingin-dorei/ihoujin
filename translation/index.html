How Will the Stranger Live? — Translation kit

異邦人はどう生きるか？ 翻訳ツール ／ ver 0.9.9

⬇ Download the translation kit (zip)

🔄 Update a translation made for an older version

What's inside

  • template.json — every line in the game, grouped by category, with empty translations
  • en.json — the bundled English translation in the same order (a good reference)
  • README.txt — how to translate and how to load your file into the game

In the game, press the globe button (🌐) on the title screen and choose “Load a translation file”. Lines you haven't translated yet stay in Japanese, so you can translate a little at a time.

日本語

ゲームのすべての文をまとめた雛形（template.json）と、同梱の英訳（en.json）、説明（README.txt・英語）です。訳したファイルは、ゲームの表題の画面の 🌐 から「翻訳ファイルを読み込む」で読み込めます。

古い版で作った翻訳（作り途中のものも）は、翻訳ファイルを新しい版へ移すページで、新しい版の一覧へ移せます。
